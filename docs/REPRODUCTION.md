## Replay commands (after input restoration)
Set `ROOT` to an isolated copy containing the original paths and archived source. New output directories must not exist. These are documented commands, not newly executed real-data runs.

```bash
cd "$ROOT"
python cbid_exp12_1_diagnostic.py --root "$ROOT" --out "$ROOT/reproduced_exp12_1" --days D E F --seeds 42 43 44
python cbid_exp12_2_adaptive.py --root "$ROOT" --out "$ROOT/reproduced_exp12_2"
python cbid_exp12_3_transfer.py --root "$ROOT" --day E --out "$ROOT/reproduced_exp12_3_E"
python cbid_exp12_3_transfer.py --root "$ROOT" --day F --out "$ROOT/reproduced_exp12_3_F"
```

Compare counts and action hashes, not runtime, to the archived results. Results from EXP-11/12 are not independent validation; see the manuscript limitations.
